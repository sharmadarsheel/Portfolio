# Vision: Personal Portfolio

## 1. Objective
To build a high-performance, visually striking personal portfolio website for Darsheel Sharma. The site combines a clean, warm sandstone and wooden-door architectural aesthetic with a modern digital interface to showcase AI and Data Science engineering projects, hackathon achievements, and technical execution.

## 2. Core Principles
* **Visual Appeal First:** Utilize a distinct, premium warm aesthetic (sandstone, wood textures, warm lighting) because it looks exceptional and stands out from generic dark-mode developer portfolios.
* **Content & Proof over Fluff:** Highlight real-world technical execution—such as AI/ML systems, hackathons (SkySight, OMNIVERSE), and technical leadership (Hacker's Unity)—rather than generic buzzwords.
* **Performance & Clean Engineering:** Ensure buttery-smooth interactions, lightweight 3D/canvas elements where appropriate, and a fully responsive layout that loads instantly.
