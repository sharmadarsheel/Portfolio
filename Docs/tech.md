# Technical Stack & Architecture

## 1. Core Framework & Styling
* **Framework:** React / Next.js / Vite (configured for optimal performance and routing).
* **Styling:** Tailwind CSS utilizing custom color tokens (`#E6D5C3` sandstone, `#1A1614` charcoal, `#D4AF37` gold).
* **Animations:** Framer Motion for smooth UI transitions and layout morphing.

## 2. Three.js / Canvas Layer
* **Library:** Three.js / React Three Fiber.
* **Usage:** Environmental depth, floating atmosphere particles, and subtle mesh geometry transitions.
* **Performance Control:** Dynamic particle reduction and lazy-loading rules for weaker mobile devices.
